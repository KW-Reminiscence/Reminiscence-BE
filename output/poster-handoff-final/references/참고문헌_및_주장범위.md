# 참고문헌과 사용 범위

## 회상 활동

Woods, B., O’Philbin, L., Farrell, E. M., Spector, A. E., and Orrell, M. (2018). Reminiscence therapy for dementia. Cochrane Database of Systematic Reviews, 2018(3), CD001120. https://doi.org/10.1002/14651858.CD001120.pub3

이 문헌은 사진과 같은 단서를 이용해 과거 경험을 이야기하는 회상 접근의 배경으로 사용할 수 있다. 보고된 이점은 작고 환경과 방식에 따라 일관되지 않으므로 Reminiscence의 예방·치료 효과를 주장하는 근거로 사용할 수 없다.

Moon, S. H., and Park, K. (2020). The effect of digital reminiscence therapy on people with dementia: a pilot randomized controlled trial. BMC Geriatrics, 20, 166. https://doi.org/10.1186/s12877-020-01563-2

이 문헌은 디지털 회상 활동의 구현과 예비 평가 사례로 사용할 수 있다. pilot 연구의 결과를 본 프로토타입의 효과로 이전하거나 임상적 유효성을 일반화할 수 없다.

## 고령 사용자 접근성

World Wide Web Consortium Web Accessibility Initiative. (2025). Older Users and Web Accessibility: Meeting the Needs of Ageing Web Users. https://www.w3.org/WAI/older-users/

World Wide Web Consortium Web Accessibility Initiative. (2010). Developing Websites for Older People: How Web Content Accessibility Guidelines 2.0 Applies. https://www.w3.org/WAI/older-users/developing/

두 자료는 일관된 화면 구조, 쉬운 문구, 지각·조작·이해 가능성을 고려한 설계의 근거로 사용할 수 있다. 현재 Reminiscence UI의 실제 사용성을 검증했다는 근거는 아니다.

## 이상 탐지

Liu, F. T., Ting, K. M., and Zhou, Z.-H. (2008). Isolation Forest. 2008 Eighth IEEE International Conference on Data Mining, 413–422. https://doi.org/10.1109/ICDM.2008.17

이 문헌은 Isolation Forest 알고리즘의 근거이다. Reminiscence가 계산한 이상 점수는 건강 위험 확률, 임상 진단 또는 응급도를 뜻하지 않는다.

## 음성 전사

OpenAI. (2026). GPT-4o Transcribe Model. https://developers.openai.com/api/docs/models/gpt-4o-transcribe

OpenAI. (2026). Audio API Reference: Create transcription. https://platform.openai.com/docs/api-reference/audio/voice-consent-list?lang=curl

공식 문서는 gpt-4o-transcribe 모델 식별자와 /v1/audio/transcriptions endpoint의 형식을 확인하는 데 사용한다. Reminiscence 저장소는 codex-lb의 OpenAI 호환 경계를 호출하므로 실제 provider의 운영 정책과 결과 품질은 별도로 검증해야 한다. 공식 benchmark를 본 Raspberry Pi 환경의 한국어 WER·지연으로 인용할 수 없다.

## 로컬 음성 합성

Supertone Inc. (2026). Supertonic: Lightning-fast, on-device, multilingual TTS. https://github.com/supertone-inc/supertonic

Supertone Inc. (2026). Supertonic 3 model card. https://huggingface.co/Supertone/supertonic-3

공식 자료는 ONNX Runtime 기반 로컬 합성, 한국어 지원과 model 특성의 근거이다. 본 장치에서의 실시간성, 자연성, 메모리 사용량과 음질은 아직 측정하지 않았다.
